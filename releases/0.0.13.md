# Caplib DolphinDB 插件 0.0.13

**Breaking change：** `createPricingSettings` 现在只接受 **9 个必填参数**的正式形式
（currency, pricingMethod, incCurrent, cashFlows, specificPricingRequests INT[],
modelHandle, pdeHandle, mcHandle, handle，另可选 returnJson BOOL），不再兼容不含
`specificPricingRequests` 的旧 8 参形式。该参数现必填，`BondSpecificPricingRequest`
枚举值 0–8 见文档。升级时请将旧调用补入 SPR 列表（如息票定价使用 `[1,2,3,4,5,6,7,8]`）。

## 变更

- **输入校验全面收紧（145 处负例已覆盖）**：
  - 数值边界：nominal、strike、asset、buyAmount、barrier、rebate、spotPrice、
    underlyingPrice、scaling、volatility、hazardRate、term 等参数拒绝 0 / 负值 / 非有限值；
  - 空值与容器：标量 null、全空/部分空向量、空矩阵拒绝；
  - 成对数组：fixingDates/fixingValues/fixingWeights、couponDates/knock-out 观察日程、
    pillarDates/pillarNames/pillarValues、terms/termDates 等长度不一致拒绝；
  - 类型与句柄：风险设置开关参数拒绝向量；错误类型的 ObjectCache 句柄显式报错
    （createScnAnalysisSettings、calcFxDeltaToStrike、get* 系列）；
  - 枚举：createBondLegDefinition 的 bondType、createInterestRateFixingScheduleDefinition
    的 fixingDayMode 非法值拒绝；
  - 业务规则：createFxForward / createFxSwap（两腿）/ createFxNonDeliverableForward
    拒绝 expiry 晚于 delivery，FX swap 另拒绝 far 腿早于 near 腿。
  - 少量行为按业务惯例保留宽松（负 delta 对应 PUT、CDS referencePrice=0、vols=0 的
    quanto 曲线、纯现金 asset=0、付款/定盘日程独立等），测试中均注明理由。
- **枚举一致性**：buildPmYieldCurve 的 dayCount 改用共享解析器，`ONE_ONE`、
  `BUSINESS_252` 及全部别名与其他接口行为一致。
- **文档修正**：createIrVanillaInstrumentTemplate 的 instType 清单删除 25 个被服务端
  拒收的跨资产类型（FX/EQ/CM/PM 期权族），并移除 `INVALID_*` 哨兵标签；补充
  buildIrSingleCurrencyCurve / buildIrCrossCurrencyCurve 的 targetCurveHandles 用法
  （构建后每条目标曲线可直接传给 getZeroRate 等访问器，无需额外查询接口）。
- **错误消息**：get* 系列错误句柄不再透出裸 `std::exception`，消息带参数名。

## 运行环境

- DolphinDB Server v3.00.5；Linux x86-64（glibc 2.38+）
- GCC 8.4 / ABI0 编译，官方 v3.00.5 镜像无需替换 libstdc++
- 最高 GLIBCXX 3.4.20（libPluginCapli）/ 3.4.23（libdqlibc.so），CXXABI 1.3.9/1.3.11，GLIBC 2.38
