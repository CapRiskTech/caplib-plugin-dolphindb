# Caplib DolphinDB 0.0.13

Source: `dqlab/dqlibdolphin`, branch `release-caplib`.

## Changes

- **Breaking**: `createPricingSettings` now requires `specificPricingRequests`
  (INT[] of `BondSpecificPricingRequest` 0-8) as its fifth argument. The
  documented signature is 9 required arguments plus optional `returnJson`
  (10 arguments); the legacy form without `specificPricingRequests` is
  rejected at parse time (`expects 9~10 argument(s)`).
- Net removal of 22 public API mappings versus 0.0.11 (Cap/Floor, Swaption,
  cross-currency curve builders, several `calc*` calculators, and static-data
  byte interfaces); 180 mappings remain.
- Full proto day-count convention parsing with convenience aliases
  (`ACT/360`, `ACT/365`, `30/360`, ...), `PAYER`/`RECEIVER` pay-receive
  aliases, and `ON`/`TN`/`SN`/`SW` special periods.
- `get*` curve accessors (`getDiscountFactor`, `getZeroRate`, `getFwdRate`,
  `getSurvivalProbability`, `getCreditSpread`, `getVolatility`) report
  missing or wrongly typed handles and empty server results explicitly
  instead of returning NULL.
- `calcYieldToMaturity` rejects non-finite and non-positive prices.
- Rebuild both native libraries and their C++ dependency chain with
  GCC 8.4 / ABI0; the official DolphinDB v3.00.5 C++ runtime stays unchanged.

## Package

`caplib-plugin-dolphindb-0.0.13.tar.gz` contains a single versioned directory
with both native libraries, the configured 3.00.5 descriptor, unchanged
previously published license/calendar files, `BUILD_INFO.json` and `SHA256SUMS`.
The archive and its SHA-256 sidecar are attached to the GitHub Release, not stored in Git.

Maximum requirements: GLIBCXX 3.4.20 (`libPluginCaplib.so`) / 3.4.23
(`libdqlibc.so`), CXXABI 1.3.9 / 1.3.11, GLIBC 2.38.
Target tested upstream: official DolphinDB v3.00.5, glibc 2.39, Linux x86-64.
Validation: official-image load gate, smoke test 7/7, and the 161-check issue
regression passed without replacing `libstdc++.so.6`.
