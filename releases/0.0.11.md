# Caplib DolphinDB 0.0.11

Source: `dqlab/dqlibdolphin`, branch `release-caplib`,
commit `c0cb21d193e276624acbdeb7100196038b038eba`.

The distribution update preserves the Docker and native test-framework changes
already present on distribution `main` at `4862b10`.

## Changes

- Rebuild both native libraries and their C++ dependency chain with GCC 8.4 / ABI0.
- Keep the official DolphinDB v3.00.5 C++ runtime unchanged.
- Add stricter scalar/null/finite/bounds validation and preserve supported legacy
  boolean flags and enum mappings from the upstream fixes.
- Preserve all 202 public API mappings.
- Add the upstream 133-check regression script to the native test runner.
- Update Chinese API documentation and official-image deployment instructions.
- Support local release archives in Bash and PowerShell builds.
- Validate package checksums and reject incompatible libraries during Docker build.

## Package

`caplib-plugin-dolphindb-0.0.11.tar.gz` contains a single versioned directory
with both native libraries, the configured 3.00.5 descriptor, unchanged
previously published license/calendar files, `BUILD_INFO.json` and `SHA256SUMS`.
The archive and its SHA-256 sidecar are attached to the GitHub Release, not stored in Git.

Maximum requirements: GLIBCXX 3.4.23, CXXABI 1.3.11, GLIBC 2.38.
Target tested upstream: official DolphinDB v3.00.5, glibc 2.39, Linux x86-64.
Upstream validation: 408/408 passed without replacing libstdc++.
