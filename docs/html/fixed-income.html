User Guide

Rates, bonds, credit, cross-currency IR, FI market data, and risk settings. This page contains 56 functions. Use the filter to narrow by function name, return type, parameter, or description.

Argument validity: Each parameter states exact enum labels, selector codes, ranges, positivity, shape, and cross-argument rules. “Wrapper checks” are immediate plugin validation; “business-valid” rules may instead be enforced downstream.

Error behavior:Every function throws a DolphinDB RuntimeException on failure instead of returning a fallback scalar or partial object. Service calls returning success=false surface the service err_msg; validation, cache-class/handle, parsing, and serialization failures throw as well.

Example

loadPlugin("caplib")

asOfDate = 2025.01.02;
usdCurve = caplib::createIrYieldCurve(
    asOfDate,
    [2025.07.02, 2026.01.02, 2027.01.02],
    [0.0200, 0.0215, 0.0230],
    "ZERO_RATE", "ACT_365_FIXED", "LINEAR_INTERP", "FLAT_EXTRAP",
    "CONTINUOUS_COMPOUNDING", "USD", "USD_DISCOUNT", "USD_DISC", false);

pricingResult = caplib::priceIrVanillaInstrument(
    "IR_SWAP", asOfDate, "IR_MKT", "IR_PRICING", "IR_RISK", "", "", true);
pricingJson = pricingResult[1];

createIrYieldCurve

Syntax

caplib::createIrYieldCurve(asOfDate, pillarDates DATE vector, pillarValues DOUBLE vector, curveType, dayCountConvention, interp, extrap, compounding, currency, name, handle[, returnJson])

Details

Create and cache an IR yield curve. It validates and converts the fields into an IrYieldCurve protobuf and stores it in ObjectCache for later analytics calls.

Return value

Created IrYieldCurve object on success. CAPLIB returns its ObjectCache handle; with returnJson=true, it returns [handle, protobufJson].

Parameters

asOfDate DATE type. Reference date for the created curve, surface, or build request.
Validity: Must be a non-null DolphinDB DATE scalar. It must not be later than a related end, expiry, delivery, or settlement date; the wrapper does not enforce this relationship.

pillarDates DATE vector type. Curve pillar dates aligned with pillar values.
Validity: Must be a DATE/INT date vector without nulls; length must match its companion argument. When it represents a schedule or term series it should normally be strictly increasing; the wrapper does not enforce sorting or chronology.

pillarValues DOUBLE vector type. Curve pillar values aligned with pillar dates.
Validity: Must have the documented element type and shape; numeric values must be finite; length/dimensions must match the companion argument. Unless stated otherwise, the wrapper does not require a non-empty collection.

curveType STRING type. Curve value type, such as zero-rate, discount-factor, or spread curve.
Validity: Accepted values: ZERO_RATE, LOG_DISCOUNT, FORWARD_RATE. Only the exact spellings shown are accepted.

dayCountConvention STRING type. Day-count convention used by the curve.
Validity: Accepted values: ACT_360, ACTUAL_360, ACT/360, ACT_365, ACT_365_FIXED, ACTUAL_365_FIXED, ACT/365, ACT_ACT, ACT_ACT_ISDA, ACTUAL_ACTUAL_ISDA, ACT_ACT_ICMA, ACTUAL_ACTUAL_ICMA, THIRTY_360, 30_360, 30/360, BOND_BASIS. Matching is case-insensitive.

interp STRING type. Interpolation method used between curve pillars.
Validity: Accepted values: LINEAR_INTERP, CUBIC_SPLINE_INTERP, LEFT_CONTINUOUS_FLAT_INTERP, CUBIC_HERMITE_SPLINE_INTERP. Only the exact spellings shown are accepted.

extrap STRING type. Extrapolation method used outside curve pillar range.
Validity: Accepted values: FLAT_EXTRAP, LINEAR_EXTRAP. Only the exact spellings shown are accepted.

compounding STRING type. Compounding convention for yield or discount calculations.
Validity: Accepted values: CONTINUOUS_COMPOUNDING, DISCRETE_COMPOUNDING, SIMPLE_COMPOUNDING. Only the exact spellings shown are accepted.

currency STRING type. Currency code for the instrument, curve, market data, or pricing output.
Validity: Must be a non-empty currency identifier, normally a three-letter uppercase ISO code; the wrapper does not verify ISO membership.

name STRING type. Business name stored on the created object.
Validity: Must be a non-empty STRING; the wrapper does not validate identifier character set or membership.

handle STRING type. ObjectCache key assigned to the created object and returned by the function.
Validity: Must be a non-empty ObjectCache key.

returnJson BOOL type. Optional. If omitted or false, returns only the ObjectCache handle; if true, returns [handle, protobufJson].
Validity: Must be a BOOL scalar; false and true are the only logical values.
