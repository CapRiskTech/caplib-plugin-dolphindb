DolphinDB Caplib 插件

DolphinDB Caplib 插件使用说明

面向固定收益、利率、外汇、权益、商品和信用的曲线构建、工具定价与风险分析插件。

功能说明

按标准模板编排的完整中文文档见 docs/CAPLIB_DOCUMENTATION.md。

Caplib 通过 CapRiskTech 的 `dqlibc` 计算库提供 202 个 DolphinDB 接口。按资产类别浏览逐接口说明：

固定收益、利率与信用73曲线、债券、互换、Cap/Floor、Swaption、CDS、市场数据和风险设置。 外汇39汇率计算、报价矩阵、波动率曲面、外汇现金类产品和期权定价。 商品25商品与贵金属市场数据、收益率曲线、波动率曲面和期权定价。 权益36股息曲线、波动率曲面、权益期权工具和定价。 通用29日期、静态数据、通用曲线、定价设置、风险设置和情景设置。

第三方库说明

插件依赖 CapRiskTech 提供的专有 `dqlibc` 库。该库负责底层金融计算、protobuf 数据处理和许可证校验。使用前必须准备有效的 `dqlibc.lic`（`lic_ver = 200`）。

安装插件

版本要求

组件要求
DolphinDB Server3.00.5 或更高版本；插件描述文件版本必须与 Server 一致
操作系统Linux x86-64
运行时 ABI`_GLIBCXX_USE_CXX11_ABI=0`（ABI0）
License有效的 `dqlibc.lic`

插件市场

先确认 `listRemotePlugins()` 的结果中存在 `caplib`。若存在，可安装并加载：

login("admin", "123456")
listRemotePlugins()
installPlugin("caplib")
loadPlugin("caplib")

预编译发行包

若远程列表中没有 `caplib`，将 `libPluginCaplib.so`、生成后的 `PluginCaplib.txt`、`libdqlibc.so` 和 `dqlibc.lic` 放在同一目录，并把 `calendars.bin` 放到 `data/` 子目录：

loadPlugin("/your/path/to/caplib/PluginCaplib.txt")

请使用本仓库发行包内已配置的 PluginCaplib.txt；不要部署源码仓库中的 CMake 模板。

核心概念

插件对外函数统一使用 lowerCamelCase，例如 caplib::calcYearFraction。PluginCaplib.txt 第一列保留 PascalCase C++ 实现符号，第二列记录 lowerCamelCase 外部名称。

1. 创建对象

`create*` 和 `build*` 函数在 ObjectCache 中创建曲线、报价、模板、设置、市场数据和工具。

2. 传递句柄

后续函数接收前序调用返回的 STRING 句柄；`*Handle` 参数必须引用匹配的 protobuf 类型。

3. 调用定价

定价函数依次接收工具、定价日、市场数据、定价设置、风险设置、情景设置和模式。

4. 查看 JSON

工厂和定价函数的可选 `returnJson=true` 返回 `[handle, protobufJson]`；默认仅返回句柄。

语法中的方括号表示可选参数，如 `[, returnJson BOOL]`。`asOfDate` 表示市场数据基准日，`pricingDate` 表示估值日，`calculationDate` 表示独立计算器的计算日。

数据类型转换

DolphinDB 类型转换规则
DATE转换为 `dqlibc` 日期序号；日期向量按接口要求使用 DATE 或 INT
STRING表示枚举、币种、期限、对象名称或 ObjectCache 句柄
DOUBLE表示利率、价格、波动率、本金或风险扰动，通常必须是有限值
BOOL表示开关或 `returnJson` 标志
向量/矩阵元素类型、形状和配对长度以逐接口参数表为准

参数、句柄、解析、序列化或底层服务失败时会抛出 DolphinDB `RuntimeException`。

使用示例

以下示例可直接运行，并展示加载插件、创建对象和读取结果；完整债券定价流程见 `example/FiAnalytics.dos`。

loadPlugin("PluginCaplib")

curve = caplib::createIrYieldCurve(
    2025.01.02,
    [2025.07.02, 2026.01.02, 2027.01.02],
    [0.0200, 0.0210, 0.0225],
    "ZERO_RATE", "ACT_365_FIXED", "LINEAR_INTERP", "FLAT_EXTRAP",
    "CONTINUOUS_COMPOUNDING", "CNY", "CNY_DISC", "CNY_DISC", false)

zeroRate = caplib::getZeroRate(curve, 2026.07.02)
print(zeroRate)

License

`dqlibc.lic` 可放在 `~/.dqlib/dqlibc.lic`、`/etc/dqlib/dqlibc.lic` 或与 `libdqlibc.so` 相同的目录。请通过 caprisktech.com 申请。

常见问题

`Invalid plugin file` 通常表示部署了源模板或版本不匹配；`GLIBCXX_* not found` 表示 C++ 运行库不兼容；`LICENSE_FILE_NOT_FOUND` 表示许可证不在搜索路径。

缩写
