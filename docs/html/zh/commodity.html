商品

商品与贵金属市场数据、报价矩阵、波动率曲面和定价。

用户指南

商品与贵金属市场数据、报价矩阵、波动率曲面和定价。本页包含 25 个函数。可按函数名、返回类型、参数或说明进行筛选。

参数有效性：每个参数均说明精确枚举标签、选择器代码、范围、正负性、形状和跨参数规则。“包装器检查”表示插件立即校验；“业务有效”规则可能由下游服务校验。

错误行为：所有接口失败时抛出 DolphinDB RuntimeException，不返回备用标量或部分对象。服务调用返回 success=false 时，其 err_msg 写入异常消息；参数验证、缓存类 / 句柄、解析和序列化错误同样抛出异常。

示例

loadPlugin("caplib")

cmQuoteMatrix = caplib::createCmOptionQuoteMatrix(
    "EUROPEAN", "FUTURE_UNDERLYING_TYPE", 2025.01.02,
    [2025.07.02, 2026.01.02], [["CALL", "PUT"], ["CALL", "PUT"]],
    [[100.0, 100.0], [105.0, 105.0]], [[7.1, 6.8], [8.4, 8.0]],
    "AU", "CM_QUOTES", true);

pricingResult = caplib::priceCmEuropeanOption(
    "CM_EUROPEAN", 2025.01.02, "CM_MKT", "CM_ANALYTICAL", "CM_RISK", "", "", true);

buildCmVolatilitySurface

语法

caplib::buildCmVolatilitySurface(asOfDate, underlying, definitionHandle, quoteMatrixHandle, underlyingPrices, discountCurveHandle, fwdCurveHandle, buildSettingsHandle, handle[, returnJson])

详情

构建商品波动率曲面。函数解析引用的 ObjectCache 条目，调用相关构建服务并缓存返回的 VolatilitySurface。

返回值

创建的 VolatilitySurface 对象对应的 ObjectCache 句柄，STRING 类型标量；returnJson=true 时返回 [handle, protobufJson]。

参数

asOfDate DATE 类型。曲线、曲面或构建请求的参考日期。
有效性: 必须是非空 DolphinDB DATE 标量。不得晚于相关结束、到期、交割或结算日；包装器不检查此关系。

underlying STRING 类型。标的资产、指数、商品或货币对标识。
有效性: 必须是非空 STRING；包装器不验证业务标识的字符集或成员资格。

definitionHandle STRING 类型。波动率曲面定义 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

quoteMatrixHandle STRING 类型。期权报价矩阵 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

underlyingPrices DOUBLE 向量 类型。与报价期限或校准行对齐的标的价格数组。
有效性: 所有元素必须有限并与配对日期等长；通常应为正，但可出现负价格的市场由下游业务规则决定。

discountCurveHandle STRING 类型。贴现曲线 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

fwdCurveHandle STRING 类型。远期曲线 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

buildSettingsHandle STRING 类型。构建设置 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

handle STRING 类型。分配给创建对象并由函数返回的 ObjectCache 键。
有效性: 必须是非空 ObjectCache 键。

returnJson BOOL 类型。可选。省略或为 false 时仅返回 ObjectCache 句柄；为 true 时返回 [handle, protobufJson]。
有效性: 必须是 BOOL 标量，仅可为 false 或 true。

buildPmYieldCurve

语法

caplib::buildPmYieldCurve(asOfDate, parCurveHandle, discountCurveHandle, pmTemplateHandle, spotPrice, calcJacobian, dayCountConvention, interpMethod, extrapMethod, curveType, curveName, shift, method, mode, handle[, returnJson])

详情

构建贵金属收益率曲线。函数解析引用的 ObjectCache 条目，调用相关构建服务并缓存返回的 DividendCurve。

返回值

创建的 DividendCurve 对象对应的 ObjectCache 句柄，STRING 类型标量；returnJson=true 时返回 [handle, protobufJson]。

参数

asOfDate DATE 类型。曲线、曲面或构建请求的参考日期。
有效性: 必须是非空 DolphinDB DATE 标量。不得晚于相关结束、到期、交割或结算日；包装器不检查此关系。

parCurveHandle STRING 类型。平价曲线输入对象 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

discountCurveHandle STRING 类型。贴现曲线 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

pmTemplateHandle STRING 类型。贵金属模板 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

spotPrice DOUBLE 类型。标的或贵金属的即期价格。
有效性: 必须严格为正且有限；包装器通常仅检查类型。

calcJacobian INT 类型。是否计算并返回校准雅可比信息。
有效性: 必须是 INT 标量；0 为 false，非零为 true；传 BOOL 值会被插件拒绝。。

dayCountConvention STRING 类型。计息惯例。
有效性: 值必须是以下完整 protobuf 标签之一：ACT_360, ACTUAL_360, ACT_365_FIXED, ACTUAL_365_FIXED, ACT_ACT_ICMA, ACTUAL_ACTUAL_ICMA, ACT_ACT_ISMA, ACTUAL_ACTUAL_ISMA, ACT_ACT_ISDA, ACTUAL_ACTUAL_ISDA, THIRTY_360, BOND_BASIS, THIRTY_E_360, EUROBOND_BASIS, THIRTY_E_360_ISDA, ONE_ONE, THIRTY_U_360, THIRTY_U_360_EOM, THIRTY_360_PSA, THIRTY_E_360_PLUS, THIRTY_360_IT, ACT_ACT_AFB, ACTUAL_ACTUAL_AFB, ACT_364, ACTUAL_364, ACT_365_25, ACTUAL_365_25, ACT_365_ACT, ACTUAL_365_ACTUAL, ACT_365_L, ACTUAL_365_LONG, ACT_365_NL, ACTUAL_365_NO_LEAP, ACT_ACT_YEAR, ACTUAL_ACTUAL_YEAR, BUSINESS_252。

interpMethod STRING 类型。插值方法。
有效性: 值必须是以下完整 protobuf 标签之一：LINEAR_INTERP, CUBIC_SPLINE_INTERP, LEFT_CONTINUOUS_FLAT_INTERP, SABR_INTERP, SVI_INTERP, LOG_MONEYNESS_CUBIC_SPLINE_INTERP, SABR_NORMAL_INTERP, QUADRATIC_POLYNOMIAL_INTERP, CUBIC_POLYNOMIAL_INTERP, CUBIC_HERMITE_SPLINE_INTERP。

extrapMethod STRING 类型。外推方法。
有效性: 值必须是以下完整 protobuf 标签之一：FLAT_EXTRAP, LINEAR_EXTRAP, NATURAL_EXTRAP, ADJ_FLAT_EXTRAP。

curveType STRING 类型。曲线值类型，例如零利率、贴现因子或利差。
有效性: 值必须是以下完整 protobuf 标签之一：ZERO_RATE, LOG_DISCOUNT, FORWARD_RATE。

curveName STRING 类型。曲线业务名称。
有效性: 必须是非空 STRING；包装器不验证业务标识的字符集或成员资格。

shift DOUBLE 类型。风险或校准计算使用的扰动大小。
有效性: 必须是有限 DOUBLE；除非另有说明，可为负、零或正，包装器不拒绝 NaN/无穷。

method STRING 类型。计算、校准或有限差分方法选择器。
有效性: 值必须是以下完整 protobuf 标签之一：CENTRAL_DIFFERENCE_METHOD, ONE_SIDE_DOWN_METHOD, ONE_SIDE_UP_METHOD。

mode STRING 类型。远程执行模式或服务端点；传空字符串使用默认模式。
有效性: 值必须是以下完整 protobuf 标签之一：SINGLE_THREADING_MODE, MULTI_THREADING_MODE。

handle STRING 类型。分配给创建对象并由函数返回的 ObjectCache 键。
有效性: 必须是非空 ObjectCache 键。

returnJson BOOL 类型。可选。省略或为 false 时仅返回 ObjectCache 句柄；为 true 时返回 [handle, protobufJson]。
有效性: 必须是 BOOL 标量，仅可为 false 或 true。

mktDataHandle STRING 类型。定价使用的市场数据集 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

pricingSettingsHandle STRING 类型。定价设置 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

riskSettingsHandle STRING 类型。风险设置 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

scnSettingsHandle STRING 类型。情景分析设置 ObjectCache 句柄；未使用时传空字符串。
有效性: 可为空以省略；非空时必须是已存在且 protobuf 类型匹配的 ObjectCache 键。

mode STRING 类型。远程执行模式或服务端点；传空字符串使用默认模式。
有效性: 可为空以使用默认模式；非空值会原样传给下游服务，插件未定义本地枚举或字符范围。
