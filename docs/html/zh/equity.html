用户指南

权益市场数据、股息曲线、波动率曲面、期权工具和权益定价。本页包含 36 个函数。可按函数名、返回类型、参数或说明进行筛选。

参数有效性：每个参数均说明精确枚举标签、选择器代码、范围、正负性、形状和跨参数规则。“包装器检查”表示插件立即校验；“业务有效”规则可能由下游服务校验。

错误行为：所有接口失败时抛出 DolphinDB RuntimeException，不返回备用标量或部分对象。服务调用返回 success=false 时，其 err_msg 写入异常消息；参数验证、缓存类 / 句柄、解析和序列化错误同样抛出异常。

示例

loadPlugin("caplib")

eqRisk = caplib::createEqRiskSettings(0, 0, 0, 0, "EQ_NO_RISK", true);
eqMkt = caplib::createEqMktDataSet(
    2025.01.02, "EQ_UNDERLYING", 100.0,
    "USD_DISC", "EQ_DIV", "EQ_VOL", "", "", 0.0, "EQ_MKT", true);

pricingResult = caplib::priceEqEuropeanOption(
    "EO_INST", 2025.01.02, eqMkt[0], "BSM_ANALYTICAL", eqRisk[0], "", "", true);
resultJson = pricingResult[1];

buildEqIndexDividendCurve

语法

caplib::buildEqIndexDividendCurve(asOfDate, termDates, futurePrices, optionPrices TABLE, spot, discountCurveHandle, handle[, returnJson])

详情

构建股指股息收益率曲线。函数解析引用的 ObjectCache 条目，调用相关构建服务并缓存返回的 DividendCurve。

返回值

创建的 DividendCurve 对象对应的 ObjectCache 句柄，STRING 类型标量；returnJson=true 时返回 [handle, protobufJson]。

参数

asOfDate DATE 类型。市场数据基准日或估值参考日期。
有效性: 必须是非空 DolphinDB DATE 标量。不得晚于相关结束、到期、交割或结算日；包装器不检查此关系。

termDates DATE 向量 类型。报价期限对应的到期日期数组。
有效性: 必须是不含空值的 DATE/INT 日期向量，长度须与配对参数一致。表示日程或期限序列时通常应严格递增；包装器不检查排序或日期先后关系。

futurePrices DOUBLE 向量 类型。期货价格数组。
有效性: 所有元素必须有限并与配对日期等长；通常应为正，但可出现负价格的市场由下游业务规则决定。

optionPrices TABLE 类型。期权价格矩阵或表。
有效性: 所有元素必须非负且有限，并与配对行权价/期限参数形状一致；包装器主要检查类型/形状。

spot DOUBLE 类型。当前现货价格。
有效性: 必须是有限 DOUBLE；除非另有说明，可为负、零或正，包装器不拒绝 NaN/无穷。

discountCurveHandle STRING 类型。贴现曲线 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

handle STRING 类型。分配给创建对象并由函数返回的 ObjectCache 键。
有效性: 必须是非空 ObjectCache 键。

returnJson BOOL 类型。可选。省略或为 false 时仅返回 ObjectCache 句柄；为 true 时返回 [handle, protobufJson]。
有效性: 必须是 BOOL 标量，仅可为 false 或 true。
