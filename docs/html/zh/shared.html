DolphinDB caplib 插件

通用

跨资产工具、定价设置、风险设置、情景设置以及共享 protobuf 工具。

用户指南

跨资产工具、定价设置、风险设置、情景设置以及共享 protobuf 工具。本页包含 28 个函数。可按函数名、返回类型、参数或说明进行筛选。

所有会向 ObjectCache 写入对象的函数都支持可选的最后一个参数 returnJson BOOL。省略或传入 false 时仅返回句柄；传入 true 时返回 [handle, protobufJson]。

参数有效性：每个参数均说明精确枚举标签、选择器代码、范围、正负性、形状和跨参数规则。“包装器检查”表示插件立即校验；“业务有效”规则可能由下游服务校验。

错误行为：所有接口失败时抛出 DolphinDB RuntimeException，不返回备用标量或部分对象。服务调用返回 success=false 时，其 err_msg 写入异常消息；参数验证、缓存类 / 句柄、解析和序列化错误同样抛出异常。

示例

loadPlugin("caplib")

settings = caplib::createPricingSettings(
    "USD", "ANALYTICAL", 0, 0, take(0, 0),
    "BSM_MODEL", "", "", "BSM_ANALYTICAL", false);

json = caplib::getObjectCacheJson("PricingSettings", settings);

核心与工具

calcYearFraction

语法

caplib::calcYearFraction(startDate, endDate, dayCountConvention)

详情

通过 CAPLIB 日期服务应用所选计息惯例，计算 startDate 到 endDate 的应计年化比例。

返回值

计算结果，DOUBLE 类型标量。

参数

startDate DATE 类型。起始日期。
有效性: 必须是非空 DolphinDB DATE 标量。不得晚于相关结束、到期、交割或结算日；包装器不检查此关系。

endDate DATE 类型。结束日期。
有效性: 必须是非空 DolphinDB DATE 标量。不得早于相关开始、发行或参考日；包装器不检查此关系。

dayCountConvention STRING 类型。计息惯例。
有效性: 可接受值：ACT_360, ACTUAL_360, ACT/360, ACT_365, ACT_365_FIXED, ACTUAL_365_FIXED, ACT/365, ACT_ACT, ACT_ACT_ISDA, ACTUAL_ACTUAL_ISDA, ACT_ACT_ICMA, ACTUAL_ACTUAL_ICMA, THIRTY_360, 30_360, 30/360, BOND_BASIS。不区分大小写。

createCalendar

语法

caplib::createCalendar(calName[, holidays[, specialBusinessDays]])

详情

根据名称、假日和特殊工作日构造 Calendar，将其序列化为 CalendarList 静态数据并注册到 CAPLIB。

返回值

创建或注册成功时返回 true，BOOL 类型标量；失败时抛出异常，不返回 false。

参数

calName STRING 类型。日历名称。
有效性: 每个名称必须是已注册的非空日历标识。

holidays DATE 或 INT 向量 类型。节假日日期数组。
有效性: 必须是不含空值的 DATE/INT 日期向量，长度须与配对参数一致。表示日程或期限序列时通常应严格递增；包装器不检查排序或日期先后关系。

specialBusinessDays DATE 或 INT 向量 类型。特殊工作日日期数组。
有效性: 必须是不含空值的 DATE/INT 日期向量，长度须与配对参数一致。表示日程或期限序列时通常应严格递增；包装器不检查排序或日期先后关系。

详情
