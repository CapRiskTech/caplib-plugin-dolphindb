用户指南

利率、债券、信用、跨币种利率、固定收益市场数据与风险设置。本页包含 56 个函数。可按函数名、返回类型、参数或说明进行筛选。

参数有效性：每个参数均说明精确枚举标签、选择器代码、范围、正负性、形状和跨参数规则。“包装器检查”表示插件立即校验；“业务有效”规则可能由下游服务校验。

错误行为：所有接口失败时抛出 DolphinDB RuntimeException，不返回备用标量或部分对象。服务调用返回 success=false 时，其 err_msg 写入异常消息；参数验证、缓存类 / 句柄、解析和序列化错误同样抛出异常。

createIrYieldCurve

语法

caplib::createIrYieldCurve(asOfDate, pillarDates, pillarValues, curveType, dayCountConvention, interp, extrap, compounding, currency, name, handle[, returnJson])

详情

创建并缓存利率收益率曲线。函数验证并转换字段，构造 IrYieldCurve protobuf 并存入 ObjectCache，供后续分析使用。

返回值

创建的 IrYieldCurve 对象对应的 ObjectCache 句柄，STRING 类型标量；returnJson=true 时返回 [handle, protobufJson]。

参数

asOfDate DATE 类型。曲线、曲面或构建请求的参考日期。
有效性: 必须是非空 DolphinDB DATE 标量。不得晚于相关结束、到期、交割或结算日；包装器不检查此关系。

pillarDates DATE 向量 类型。曲线节点日期数组。
有效性: 必须是不含空值的 DATE/INT 日期向量，长度须与配对参数一致。表示日程或期限序列时通常应严格递增；包装器不检查排序或日期先后关系。

pillarValues DOUBLE 向量 类型。曲线节点值数组。
有效性: 必须具有所列元素类型和形状；数值必须有限，长度/维度须与配对参数一致；除明确说明外包装器不强制非空。

curveType STRING 类型。曲线值类型，例如零利率、贴现因子或利差。
有效性: 可接受值：ZERO_RATE, LOG_DISCOUNT, FORWARD_RATE。仅接受所示精确拼写。

dayCountConvention STRING 类型。计息惯例。
有效性: 可接受值：ACT_360, ACTUAL_360, ACT/360, ACT_365, ACT_365_FIXED, ACTUAL_365_FIXED, ACT/365, ACT_ACT, ACT_ACT_ISDA, ACTUAL_ACTUAL_ISDA, ACT_ACT_ICMA, ACTUAL_ACTUAL_ICMA, THIRTY_360, 30_360, 30/360, BOND_BASIS。不区分大小写。

interp STRING 类型。插值方法。
有效性: 可接受值：LINEAR_INTERP, CUBIC_SPLINE_INTERP, LEFT_CONTINUOUS_FLAT_INTERP, CUBIC_HERMITE_SPLINE_INTERP。仅接受所示精确拼写。

extrap STRING 类型。外推方法。
有效性: 可接受值：FLAT_EXTRAP, LINEAR_EXTRAP。仅接受所示精确拼写。

compounding STRING 类型。复利约定。
有效性: 可接受值：CONTINUOUS_COMPOUNDING, DISCRETE_COMPOUNDING, SIMPLE_COMPOUNDING。仅接受所示精确拼写。

currency STRING 类型。币种代码。
有效性: 必须是非空币种标识，通常为三个大写 ISO 字母；包装器不校验币种代码是否为有效 ISO 代码。

name STRING 类型。写入创建对象的业务名称。
有效性: 必须是非空 STRING；包装器不验证业务标识的字符集或成员资格。

handle STRING 类型。分配给创建对象并由函数返回的 ObjectCache 键。
有效性: 必须是非空 ObjectCache 键。

returnJson BOOL 类型。可选。省略或为 false 时仅返回 ObjectCache 句柄；为 true 时返回 [handle, protobufJson]。
有效性: 必须是 BOOL 标量，仅可为 false 或 true。
