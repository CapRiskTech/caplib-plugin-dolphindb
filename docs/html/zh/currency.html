外汇计算器、报价矩阵、波动率曲面、现金类产品和期权定价。

用户指南

外汇计算器、报价矩阵、波动率曲面、现金类产品和期权定价。本页包含 35 个函数。可按函数名、返回类型、参数或说明进行筛选。

参数有效性：每个参数均说明精确枚举标签、选择器代码、范围、正负性、形状和跨参数规则。“包装器检查”表示插件立即校验；“业务有效”规则可能由下游服务校验。

错误行为：所有接口失败时抛出 DolphinDB RuntimeException，不返回备用标量或部分对象。服务调用返回 success=false 时，其 err_msg 写入异常消息；参数验证、缓存类 / 句柄、解析和序列化错误同样抛出异常。

示例

loadPlugin("caplib")

asOfDate = 2025.01.02
spot = caplib::createFxSpotRate(1.10, "EUR", "USD", asOfDate, asOfDate, "EURUSD_SPOT", false)
usdCurve = caplib::createFlatIrYieldCurve(asOfDate, "USD", 0.02, "USD_DISC", false)
eurCurve = caplib::createFlatIrYieldCurve(asOfDate, "EUR", 0.01, "EUR_DISC", false)
vol = caplib::createFlatFxVolatilitySurface(asOfDate, "EURUSD", 0.10, "EURUSD_VOL", false)
fxMkt = caplib::createFxMktDataSet(asOfDate, usdCurve, eurCurve, spot, vol, "FX_MKT_NAME", "FX_MKT", false)
print(fxMkt)

calcFxAtmStrike

语法

caplib::calcFxAtmStrike(atmType, expiryDate, volSurfaceHandle, fxSpotRateHandle, domesticDiscountCurveHandle, foreignDiscountCurveHandle)

详情

返回值

计算结果，DOUBLE 类型标量。

参数

atmType STRING 类型。ATM 行权价约定。
有效性: 值必须是以下完整 protobuf 标签之一：ATM_FORWARD, ATM_DNS_PIPS, ATM_DNS_PERCENTAGE, ATM_SPOT。

expiryDate DATE 类型。该计算使用的日期。
有效性: 必须是非空 DolphinDB DATE 标量。不得早于相关开始、发行或参考日；包装器不检查此关系。

volSurfaceHandle STRING 类型。FxVolatilitySurface 的 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

fxSpotRateHandle STRING 类型。FxSpotRate 的 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

domesticDiscountCurveHandle STRING 类型。domestic IrYieldCurve 的 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

foreignDiscountCurveHandle STRING 类型。foreign IrYieldCurve 的 ObjectCache 句柄。
有效性: 必须是非空、已存在且 protobuf 类型匹配的 ObjectCache 键。

语法

caplib::createFxOptionQuoteMatrix(leftCcy, rightCcy, asOfDate, terms, quoteNames, quotes, handle[, returnJson])

详情

返回值

参数

leftCcy STRING 类型。币种代码。

rightCcy STRING 类型。币种代码。

有效性: 必须是非空 DolphinDB DATE 标量。不得晚于相关结束、到期、交割或结算日；包装器不检查此关系。

terms STRING 向量 类型。报价期限数组。
有效性: 每个元素必须使用正整数加 Y/M/W/D（或完整英文单位）；不支持小数，字符串解析不保留负号。

handle STRING 类型。分配给创建对象并由函数返回的 ObjectCache 键。
有效性: 必须是非空 ObjectCache 键。

returnJson BOOL 类型。可选。省略或为 false 时仅返回 ObjectCache 句柄；为 true 时返回 [handle, protobufJson]。
有效性: 必须是 BOOL 标量，仅可为 false 或 true。
