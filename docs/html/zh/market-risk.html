DolphinDB caplib 插件

市场风险

历史模拟情景生成、风险价值（VaR）与期望损失（ES）。

用户指南

市场风险：历史模拟情景生成器（FX 即期、FX 波动率）与 VaR / 期望损失（ES）度量。本页包含 4 个函数。

错误行为：所有接口失败时抛出 DolphinDB RuntimeException，不返回备用标量或部分对象。服务调用返回 success=false 时，其 err_msg 写入异常消息；参数验证、缓存类 / 句柄、解析和序列化错误同样抛出异常。

示例

loadPlugin("caplib")
samples = [-100.0, -50.0, 0.0, 50.0, 100.0]
vaR = caplib::calcVaR(samples, 0.95, false)
print(vaR.value_at_risk)

市场风险

buildHistSimFxSpotRate

语法

caplib::buildHistSimFxSpotRate(simDate, referenceSpot, histStart, histEnd, useTemplate, fxSpotTemplate, handle[, returnJson])

详情

通过历史模拟构建 FX 即期汇率情景。可选应用 FxSpotTemplate。

返回值

创建的 FxSpotRate 对象对应的 ObjectCache 句柄，STRING 类型标量；returnJson=true 时返回 [handle, protobufJson]。

参数

simDate DATE 类型。模拟基准日期。
有效性: 必须是非空 DolphinDB DATE 标量。

referenceSpot STRING 类型。参考 FxSpotRate 句柄。
有效性: 必须是已存在的 FxSpotRate 对象的非空 ObjectCache 键。

histStart STRING 类型。历史起始 FxSpotRate 句柄。
有效性: 必须是已存在的 FxSpotRate 对象的非空 ObjectCache 键。

histEnd STRING 类型。历史结束 FxSpotRate 句柄。
有效性: 必须是已存在的 FxSpotRate 对象的非空 ObjectCache 键。

useTemplate BOOL 类型。是否应用 FX 即期模板；为 true 时 fxSpotTemplate 必填。
有效性: 必须是 BOOL 标量。为 true 时 fxSpotTemplate 须为有效的 FxSpotTemplate 句柄；为 false 时须传空串。

fxSpotTemplate STRING 类型。FxSpotTemplate 句柄；useTemplate 为 false 时传空串。
有效性: useTemplate 为 true 时必须是已存在的 FxSpotTemplate 对象的非空 ObjectCache 键；否则传空串。

handle STRING 类型。结果 FxSpotRate 的 ObjectCache 键。
有效性: 必须是非空 ObjectCache 键。

returnJson BOOL 类型。可选。缺省或为 false 时仅返回 ObjectCache 句柄；为 true 时返回 [handle, protobufJson]。
有效性: 必须是 BOOL 标量。

buildHistSimFxVolSurface

语法

caplib::buildHistSimFxVolSurface(simDate, referenceVolSurf, histStart, histEnd, volSurfaceDates, volSurfaceStrikes, spot, domCurve, forCurve, settings, handle[, returnJson])

详情

基于历史模拟生成一个 FX 波动率曲面情景，需参考/历史曲面、行权价网格、即期及本币/外币贴现曲线。

返回值

创建的 FxVolatilitySurface 对象对应的 ObjectCache 句柄，STRING 类型标量；returnJson=true 时返回 [handle, protobufJson]。

参数

simDate DATE 类型。模拟基准日期。
有效性: 必须是非空 DolphinDB DATE 标量。

referenceVolSurf STRING 类型。参考 FxVolatilitySurface 句柄。
有效性: 必须是已存在的 FxVolatilitySurface 对象的非空 ObjectCache 键。

histStart STRING 类型。历史起始 FxVolatilitySurface 句柄。
有效性: 必须是已存在的 FxVolatilitySurface 对象的非空 ObjectCache 键。

histEnd STRING 类型。历史结束 FxVolatilitySurface 句柄。
有效性: 必须是已存在的 FxVolatilitySurface 对象的非空 ObjectCache 键。

volSurfaceDates DATE 向量 类型。目标曲面日期，至少两个。
有效性: 必须是无空值的 DATE 向量，且至少两个日期；长度须与 volSurfaceStrikes 的行权价集个数一致。

volSurfaceStrikes ANY 类型。每个目标日期一行权价集（DOUBLE 向量 的向量）；形状须与日期数匹配。
有效性: 必须是无空值的 DOUBLE 向量的向量；长度须与 volSurfaceDates 的日期个数一致。

spot STRING 类型。FxSpotRate 句柄。
有效性: 必须是已存在的 FxSpotRate 对象的非空 ObjectCache 键。

domCurve STRING 类型。本币 IrYieldCurve 句柄。
有效性: 必须是已存在的 IrYieldCurve 对象的非空 ObjectCache 键。

forCurve STRING 类型。外币 IrYieldCurve 句柄。
有效性: 必须是已存在的 IrYieldCurve 对象的非空 ObjectCache 键。

settings STRING 类型。VolatilitySurfaceBuildSettings 句柄，可传空串。
有效性: 必须是已存在的 VolatilitySurfaceBuildSettings 对象的 ObjectCache 键，或空串。

handle STRING 类型。结果 FxVolatilitySurface 的 ObjectCache 键。
有效性: 必须是非空 ObjectCache 键。

returnJson BOOL 类型。可选。缺省或为 false 时仅返回 ObjectCache 句柄；为 true 时返回 [handle, protobufJson]。
有效性: 必须是 BOOL 标量。

示例

calcVaR

语法

caplib::calcVaR(profitLossSamples, probability, antithetic)

详情

计算盈亏样本的 VaR 风险价值。

返回值

字典，含键 value_at_risk（VaR 值）与 value_at_risk_mirrored（对偶样本镜像 VaR），值均为 DOUBLE 标量。

参数

profitLossSamples DOUBLE 向量 类型。盈亏样本序列。
有效性: 必须是无空值且非空的 DOUBLE 向量。

probability DOUBLE 类型。置信水平，严格在 (0,1) 内。
有效性: 必须是严格在 (0,1) 内的 DOUBLE 标量。

antithetic BOOL 类型。是否同时计算对偶镜像 VaR。
有效性: 必须是 BOOL 标量。

示例

完整可执行示例见文档首页“使用示例”。

probability DOUBLE 类型。置信水平，严格在 (0,1) 内。
有效性: 必须是严格在 (0,1) 内的 DOUBLE 标量。

antithetic BOOL 类型。是否同时计算对偶镜像期望损失。
有效性: 必须是 BOOL 标量。
