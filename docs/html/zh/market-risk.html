DolphinDB caplib 插件

通用

跨资产工具、定价设置、风险设置、情景设置以及共享 protobuf 工具。

用户指南

市场风险：历史模拟情景生成器（IR/信用曲线、FX 即期、FX 波动率）与 VaR / 期望损失（ES）度量。本页包含 6 个函数。

Example

loadPlugin("PluginCaplib")
vaR = caplib::calcVaR([-100.0, -50.0, 0.0, 50.0, 100.0], 0.95, false);

市场风险

buildHistSimIrYieldCurve

语法

caplib::buildHistSimIrYieldCurve(simDate DATE, referenceCurve STRING, histStart STRING, histEnd STRING, curveDates DATE[], handle STRING[, returnJson BOOL])

详情

基于历史模拟生成一条 IR 收益率曲线情景（服务 HIST_SIM_IR_YIELD_CURVE_SCN_GENERATOR）：把参考与历史曲线插值到目标曲线日期。

IrYieldCurve 句柄

返回值

返回：IrYieldCurve 句柄 存入 ObjectCache；returnJson=true 时返回 [handle, protobufJson]。

参数
参数类型 / 形状说明
simDateDATE模拟基准日。
referenceCurveSTRING参考 IrYieldCurve 句柄。
histStartSTRING历史起始 IrYieldCurve 句柄。
histEndSTRING历史结束 IrYieldCurve 句柄。
curveDatesDATE[]输出曲线目标日期，至少两个。
handleSTRING结果 IrYieldCurve 的缓存键。

buildHistSimCreditCurve

语法

caplib::buildHistSimCreditCurve(simDate DATE, referenceCurve STRING, histStart STRING, histEnd STRING, curveDates DATE[], handle STRING[, returnJson BOOL])

详情

基于历史模拟生成一条信用利差曲线情景（服务 HIST_SIM_CREDIT_CURVE_SCN_GENERATOR），参数同 buildHistSimIrYieldCurve，曲线类型为 CreditCurve。

CreditCurve 句柄

返回值

返回：CreditCurve 句柄 存入 ObjectCache；returnJson=true 时返回 [handle, protobufJson]。

参数
参数类型 / 形状说明
simDateDATE模拟基准日。
referenceCurveSTRING参考 CreditCurve 句柄。
histStartSTRING历史起始 CreditCurve 句柄。
histEndSTRING历史结束 CreditCurve 句柄。
curveDatesDATE[]目标日期，至少两个且期限为正。
handleSTRING结果 CreditCurve 的缓存键。

buildHistSimFxSpotRate

语法

caplib::buildHistSimFxSpotRate(simDate DATE, referenceSpot STRING, histStart STRING, histEnd STRING, useTemplate BOOL, fxSpotTemplate STRING, handle STRING[, returnJson BOOL])

详情

基于历史模拟生成一个 FX 即期汇率情景（服务 HIST_SIM_FX_SPOT_RATE_SCN_GENERATOR），可选应用 FxSpotTemplate。

FxSpotRate 句柄

返回值

返回：FxSpotRate 句柄 存入 ObjectCache；returnJson=true 时返回 [handle, protobufJson]。

参数
参数类型 / 形状说明
simDateDATE模拟基准日。
referenceSpotSTRING参考 FxSpotRate 句柄。
histStartSTRING历史起始 FxSpotRate 句柄。
histEndSTRING历史结束 FxSpotRate 句柄。
useTemplateBOOL是否应用 FX 即期模板；为 true 时 fxSpotTemplate 必填。
fxSpotTemplateSTRINGFxSpotTemplate 句柄；useTemplate=false 传空串。
handleSTRING结果 FxSpotRate 的缓存键。

buildHistSimFxVolSurface

语法

caplib::buildHistSimFxVolSurface(simDate DATE, referenceVolSurf STRING, histStart STRING, histEnd STRING, volSurfaceDates DATE[], volSurfaceStrikes ANY, spot STRING, domCurve STRING, forCurve STRING, settings STRING, handle STRING[, returnJson BOOL])

详情

基于历史模拟生成一个 FX 波动率曲面情景（服务 HIST_SIM_FX_VOL_SURFACE_SCN_GENERATOR），需参考/历史曲面、行权价网格、即期及本币/外币贴现曲线。

FxVolatilitySurface 句柄

返回值

返回：FxVolatilitySurface 句柄 存入 ObjectCache；returnJson=true 时返回 [handle, protobufJson]。

参数
参数类型 / 形状说明
referenceVolSurf / histStart / histEndSTRING参考/历史起始/历史结束 FxVolatilitySurface 句柄。
volSurfaceDatesDATE[]目标曲面日期，至少两个。
volSurfaceStrikesANY每个目标日期一行权价集（DOUBLE[] 的向量）；形状须与日期数匹配。
spotSTRINGFxSpotRate 句柄。
domCurveSTRING本币 IrYieldCurve 句柄。
forCurveSTRING外币 IrYieldCurve 句柄。
settingsSTRINGVolatilitySurfaceBuildSettings 句柄，可传空串。

calcVaR

语法

caplib::calcVaR(profitLossSamples DOUBLE[], probability DOUBLE, antithetic BOOL)

详情

计算盈亏样本的 VaR 风险价值（服务 CALCULATE_VALUE_AT_RISK）。

DOUBLE

返回值

返回：DOUBLE 存入 ObjectCache；returnJson=true 时返回 [handle, protobufJson]。

参数
参数类型 / 形状说明
profitLossSamplesDOUBLE[]盈亏样本序列。
probabilityDOUBLE置信水平，严格在 (0,1) 内。
antitheticBOOL是否同时计算对偶镜像 VaR。

DOUBLE

返回值

返回：DOUBLE 存入 ObjectCache；returnJson=true 时返回 [handle, protobufJson]。

参数
参数类型 / 形状说明
profitLossSamplesDOUBLE[]盈亏样本序列。
probabilityDOUBLE置信水平，严格在 (0,1) 内。
antitheticBOOL是否同时计算对偶镜像期望损失。
