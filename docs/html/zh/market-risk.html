DolphinDB caplib 插件

通用

跨资产工具、定价设置、风险设置、情景设置以及共享 protobuf 工具。

📘 完整规范文档（含参数取值、错误行为）见 Markdown 版 DQLIB_DOCUMENTATION.md。

用户指南

市场风险：历史模拟情景生成器（FX 即期、FX 波动率）与 VaR / 期望损失（ES）度量。本页包含 4 个函数。

错误行为：所有接口失败时抛出 DolphinDB RuntimeException，不返回备用标量或部分对象。服务调用返回 success=false 时，其 err_msg 写入异常消息；参数验证、缓存类 / 句柄、解析和序列化错误同样抛出异常。

示例

loadPlugin("caplib")
vaR = caplib::calcVaR([-100.0, -50.0, 0.0, 50.0, 100.0], 0.95, false);

市场风险

buildHistSimFxSpotRate

语法

caplib::buildHistSimFxSpotRate(simDate DATE, referenceSpot STRING, histStart STRING, histEnd STRING, useTemplate BOOL, fxSpotTemplate STRING, handle STRING[, returnJson BOOL])

详情

通过历史模拟构建 FX 即期汇率情景（服务 HIST_SIM_FX_SPOT_RATE_SCN_GENERATOR）。可选应用 FxSpotTemplate。

FxSpotRate 句柄

返回值

返回：FxSpotRate 句柄 存入 ObjectCache；returnJson=true 时返回 [handle, protobufJson]。

参数
参数类型 / 形状说明
simDateDATE模拟基准日期。
有效性: 必须是非空 DolphinDB DATE 标量。
referenceSpotSTRING参考 FxSpotRate 句柄。
有效性: 必须是已存在的 FxSpotRate 对象的非空 ObjectCache 键。
histStartSTRING历史起始 FxSpotRate 句柄。
有效性: 必须是已存在的 FxSpotRate 对象的非空 ObjectCache 键。
histEndSTRING历史结束 FxSpotRate 句柄。
有效性: 必须是已存在的 FxSpotRate 对象的非空 ObjectCache 键。
useTemplateBOOL是否应用 FX 即期模板；为 true 时 fxSpotTemplate 必填。
有效性: 必须是 BOOL 标量。为 true 时 fxSpotTemplate 须为有效的 FxSpotTemplate 句柄；为 false 时须传空串。
fxSpotTemplateSTRINGFxSpotTemplate 句柄；useTemplate 为 false 时传空串。
有效性: useTemplate 为 true 时必须是已存在的 FxSpotTemplate 对象的非空 ObjectCache 键；否则传空串。
handleSTRING结果 FxSpotRate 的 ObjectCache 键。
有效性: 必须是非空 ObjectCache 键。
returnJsonBOOL可选。缺省或为 false 时仅返回 ObjectCache 句柄；为 true 时返回 [handle, protobufJson]。
有效性: 必须是 BOOL 标量。

buildHistSimFxVolSurface

语法

caplib::buildHistSimFxVolSurface(simDate DATE, referenceVolSurf STRING, histStart STRING, histEnd STRING, volSurfaceDates DATE 向量, volSurfaceStrikes ANY, spot STRING, domCurve STRING, forCurve STRING, settings STRING, handle STRING[, returnJson BOOL])

详情

基于历史模拟生成一个 FX 波动率曲面情景（服务 HIST_SIM_FX_VOL_SURFACE_SCN_GENERATOR），需参考/历史曲面、行权价网格、即期及本币/外币贴现曲线。

FxVolatilitySurface 句柄

返回值

返回：FxVolatilitySurface 句柄 存入 ObjectCache；returnJson=true 时返回 [handle, protobufJson]。

参数
参数类型 / 形状说明
simDateDATE模拟基准日期。
有效性: 必须是非空 DolphinDB DATE 标量。
referenceVolSurf / histStart / histEndSTRING参考/历史起始/历史结束 FxVolatilitySurface 句柄。
有效性: 各自必须是已存在的 FxVolatilitySurface 对象的非空 ObjectCache 键。
volSurfaceDatesDATE 向量目标曲面日期，至少两个。
有效性: 必须是无空值的 DATE 向量，且至少两个日期；长度须与 volSurfaceStrikes 的行权价集个数一致。
volSurfaceStrikesANY每个目标日期一行权价集（DOUBLE 向量 的向量）；形状须与日期数匹配。
有效性: 必须是无空值的 DOUBLE 向量的向量；长度须与 volSurfaceDates 的日期个数一致。
spotSTRINGFxSpotRate 句柄。
有效性: 必须是已存在的 FxSpotRate 对象的非空 ObjectCache 键。
domCurveSTRING本币 IrYieldCurve 句柄。
有效性: 必须是已存在的 IrYieldCurve 对象的非空 ObjectCache 键。
forCurveSTRING外币 IrYieldCurve 句柄。
有效性: 必须是已存在的 IrYieldCurve 对象的非空 ObjectCache 键。
settingsSTRINGVolatilitySurfaceBuildSettings 句柄，可传空串。
有效性: 必须是已存在的 VolatilitySurfaceBuildSettings 对象的 ObjectCache 键，或空串。
handleSTRING结果 FxVolatilitySurface 的 ObjectCache 键。
有效性: 必须是非空 ObjectCache 键。
returnJsonBOOL可选。缺省或为 false 时仅返回 ObjectCache 句柄；为 true 时返回 [handle, protobufJson]。
有效性: 必须是 BOOL 标量。

calcVaR

语法

caplib::calcVaR(profitLossSamples DOUBLE 向量, probability DOUBLE, antithetic BOOL)

详情

计算盈亏样本的 VaR 风险价值（服务 CALCULATE_VALUE_AT_RISK）。

DICTIONARY

返回值

返回：字典，含键 value_at_risk（VaR 值）与 value_at_risk_mirrored（对偶样本镜像 VaR），值均为 DOUBLE 标量。

参数
参数类型 / 形状说明
profitLossSamplesDOUBLE 向量盈亏样本序列。
有效性: 必须是无空值且非空的 DOUBLE 向量。
probabilityDOUBLE置信水平，严格在 (0,1) 内。
有效性: 必须是严格在 (0,1) 内的 DOUBLE 标量。
antitheticBOOL是否同时计算对偶镜像 VaR。
有效性: 必须是 BOOL 标量。

calcExpectedShortfall

语法

caplib::calcExpectedShortfall(profitLossSamples DOUBLE 向量, probability DOUBLE, antithetic BOOL)

详情

计算盈亏样本的 ES 期望损失（服务 CALCULATE_EXPECTED_SHORT_FALL）。

DICTIONARY

返回值

返回：字典，含键 expected_shortfall（期望损失值）与 expected_shortfall_mirrored（对偶样本镜像期望损失），值均为 DOUBLE 标量。

参数
参数类型 / 形状说明
profitLossSamplesDOUBLE 向量盈亏样本序列。
有效性: 必须是无空值且非空的 DOUBLE 向量。
probabilityDOUBLE置信水平，严格在 (0,1) 内。
有效性: 必须是严格在 (0,1) 内的 DOUBLE 标量。
antitheticBOOL是否同时计算对偶镜像期望损失。
有效性: 必须是 BOOL 标量。
