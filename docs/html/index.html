DolphinDB Caplib plugin

DolphinDB Caplib Plugin User Guide

Curve construction, instrument pricing, and risk analysis for fixed income, interest rates, FX, equity, commodities, and credit.

Overview

The complete Chinese guide following the standard documentation template is available at docs/CAPLIB_DOCUMENTATION.md.

Caplib exposes 202 DolphinDB functions backed by the CapRiskTech `dqlibc` calculation library.

Fixed Income, IR, and Credit73Curves, bonds, swaps, cap/floor, swaptions, CDS, market data, and risk settings. Foreign Exchange39FX calculators, quote matrices, volatility surfaces, cash products, and option pricing. Commodity25Commodity and precious-metal market data, curves, volatility surfaces, and pricing. Equity36Dividend curves, volatility surfaces, equity instruments, and pricing. Common29Date utilities, static data, common curves, pricing, risk, and scenario settings.

Third-party library

The plugin depends on the proprietary `dqlibc` library supplied by CapRiskTech. It provides the underlying financial calculations, protobuf handling, and license verification. A valid `dqlibc.lic` file with `lic_ver = 200` is required.

Plugin repository

Check whether `listRemotePlugins()` contains `caplib`. If it does, install and load it directly:

login("admin", "123456")
listRemotePlugins()
installPlugin("caplib")
loadPlugin("caplib")

Prebuilt package

If `caplib` is not listed remotely, place `libPluginCaplib.so`, the generated `PluginCaplib.txt`, `libdqlibc.so`, and `dqlibc.lic` together, with `calendars.bin` in the `data/` subdirectory:

loadPlugin("/your/path/to/caplib/PluginCaplib.txt")

Use the configured PluginCaplib.txt from this repository's release archive; do not deploy the CMake template from the source repository.

Core concepts

Public functions use lowerCamelCase, for example caplib::calcYearFraction. Column 1 of PluginCaplib.txt retains the PascalCase C++ symbol; column 2 stores the corresponding lowerCamelCase external name.

1. Create objects

`create*` and `build*` functions store curves, quotes, templates, settings, market data, and instruments in ObjectCache.

2. Pass handles

Downstream calls use returned STRING handles; each `*Handle` argument must reference the expected protobuf type.

3. Price consistently

Pricing calls take instrument, pricing date, market data, pricing settings, risk settings, scenario settings, and mode.

4. Inspect JSON

Optional `returnJson=true` returns `[handle, protobufJson]`; omission or `false` returns the handle only.

Square brackets in a signature indicate optional parameters. `asOfDate` is a market-data reference date, `pricingDate` is a valuation date, and `calculationDate` is the date of a standalone calculation.

Data type conversion

DolphinDB typeConversion
DATEConverted to the `dqlibc` date serial; date vectors use DATE or INT where documented
STRINGEnum label, currency, tenor, object name, or ObjectCache handle
DOUBLERate, price, volatility, notional, or risk bump; normally required to be finite
BOOLFeature switch or `returnJson` flag
Vector/matrixElement type, shape, and paired lengths are defined by each parameter table

Validation, handle-type, parsing, serialization, and service failures raise a DolphinDB `RuntimeException`.

Example

This runnable example loads the plugin, creates a curve, and queries it. See `example/FiAnalytics.dos` for an end-to-end bond pricing workflow.

loadPlugin("PluginCaplib")

curve = caplib::createIrYieldCurve(
    2025.01.02,
    [2025.07.02, 2026.01.02, 2027.01.02],
    [0.0200, 0.0210, 0.0225],
    "ZERO_RATE", "ACT_365_FIXED", "LINEAR_INTERP", "FLAT_EXTRAP",
    "CONTINUOUS_COMPOUNDING", "CNY", "CNY_DISC", "CNY_DISC", false)

zeroRate = caplib::getZeroRate(curve, 2026.07.02)
print(zeroRate)

License

Place `dqlibc.lic` in `~/.dqlib/dqlibc.lic`, `/etc/dqlib/dqlibc.lic`, or beside `libdqlibc.so`. Request a license from caprisktech.com.

FAQ

`Invalid plugin file` normally means a source template or mismatched version was deployed. `GLIBCXX_* not found` indicates an incompatible C++ runtime. `LICENSE_FILE_NOT_FOUND` means the license is outside the search path.
