Market Risk

Historical-simulation scenario generation, Value at Risk (VaR), and Expected Shortfall (ES).

📘 Full standard documentation (parameter values, error behavior) is in the Markdown version DQLIB_DOCUMENTATION.md.

User Guide

Market Risk: historical-simulation scenario generators (FX spot, FX volatility) and VaR / Expected Shortfall measures. This page contains 4 functions.

Every function that stores an object in ObjectCache accepts an optional final returnJson BOOL argument. Pass true to return [handle, protobufJson].

Error behavior:Every function throws a DolphinDB RuntimeException on failure instead of returning a fallback scalar or partial object. Service calls returning success=false surface the service err_msg; validation, cache-class/handle, parsing, and serialization failures throw as well.

Example

loadPlugin("caplib")
samples = [-100.0, -50.0, 0.0, 50.0, 100.0]
vaR = caplib::calcVaR(samples, 0.95, false)
print(vaR.value_at_risk)

Market Risk

buildHistSimFxSpotRate

Syntax

caplib::buildHistSimFxSpotRate(simDate, referenceSpot, histStart, histEnd, useTemplate, fxSpotTemplate, handle[, returnJson])

Details

Build an FX spot-rate scenario by historical simulation . Optionally applies an FxSpotTemplate.

Return value

ObjectCache handle of the created FxSpotRate object, STRING scalar; with returnJson=true a [handle, protobufJson] pair is returned.

Parameters

simDate DATE type. Simulation reference date.
Validity: Must be a non-null DolphinDB DATE scalar.

referenceSpot STRING type. Handle of the reference FxSpotRate.
Validity: Must be a non-empty ObjectCache key of an existing FxSpotRate object.

histStart STRING type. Handle of the historical-start FxSpotRate.
Validity: Must be a non-empty ObjectCache key of an existing FxSpotRate object.

histEnd STRING type. Handle of the historical-end FxSpotRate.
Validity: Must be a non-empty ObjectCache key of an existing FxSpotRate object.

useTemplate BOOL type. Whether to apply an FX spot template; if true, fxSpotTemplate is required.
Validity: Must be a BOOL scalar. When true, fxSpotTemplate must be a valid FxSpotTemplate handle; when false, pass an empty string.

fxSpotTemplate STRING type. Handle of the FxSpotTemplate; empty when useTemplate is false.
Validity: Must be a non-empty ObjectCache key of an existing FxSpotTemplate object when useTemplate is true; an empty string otherwise.

handle STRING type. ObjectCache key for the result FxSpotRate.
Validity: Must be a non-empty ObjectCache key.

returnJson BOOL type. Optional. If omitted or false, returns only the ObjectCache handle; if true, returns [handle, protobufJson].
Validity: Must be a BOOL scalar.

buildHistSimFxVolSurface

Syntax

caplib::buildHistSimFxVolSurface(simDate, referenceVolSurf, histStart, histEnd, volSurfaceDates DATE vector, volSurfaceStrikes, spot, domCurve, forCurve, settings, handle[, returnJson])

Details

Build an FX volatility-surface scenario by historical simulation from reference and historical surfaces, a strike/target-date grid, spot rate, and domestic/foreign discount curves.

Return value

ObjectCache handle of the created FxVolatilitySurface object, STRING scalar; with returnJson=true a [handle, protobufJson] pair is returned.

Parameters

simDate DATE type. Simulation reference date.
Validity: Must be a non-null DolphinDB DATE scalar.

referenceVolSurf / histStart / histEnd STRING type. Handles of the reference, historical-start and historical-end FxVolatilitySurface.
Validity: Each must be a non-empty ObjectCache key of an existing FxVolatilitySurface object.

volSurfaceDates DATE vector type. Target surface dates; at least two.
Validity: Must be a DATE vector without nulls, containing at least two dates; its length must match the number of strike sets in volSurfaceStrikes.

volSurfaceStrikes ANY type. Per-date strike sets (a vector of DOUBLE vector); shape must match the date count.
Validity: Must be a vector of DOUBLE vectors without nulls; its length must equal the number of dates in volSurfaceDates.

spot STRING type. Handle of the FxSpotRate.
Validity: Must be a non-empty ObjectCache key of an existing FxSpotRate object.

domCurve STRING type. Handle of the domestic IrYieldCurve.
Validity: Must be a non-empty ObjectCache key of an existing IrYieldCurve object.

forCurve STRING type. Handle of the foreign IrYieldCurve.
Validity: Must be a non-empty ObjectCache key of an existing IrYieldCurve object.

settings STRING type. Handle of VolatilitySurfaceBuildSettings; may be empty.
Validity: Must be an ObjectCache key of an existing VolatilitySurfaceBuildSettings object, or an empty string.

handle STRING type. ObjectCache key for the result FxVolatilitySurface.
Validity: Must be a non-empty ObjectCache key.

returnJson BOOL type. Optional. If omitted or false, returns only the ObjectCache handle; if true, returns [handle, protobufJson].
Validity: Must be a BOOL scalar.

calcVaR

Syntax

caplib::calcVaR(profitLossSamples DOUBLE vector, probability, antithetic)

Details

Compute the Value-at-Risk of a profit-and-loss sample series .

Return value

a dictionary with keys value_at_risk (VaR) and value_at_risk_mirrored (mirror VaR of the antithetic sample); both values are DOUBLE scalars.

Parameters

profitLossSamples DOUBLE vector type. Profit/loss sample series.
Validity: Must be a DOUBLE vector without nulls and must not be empty.

probability DOUBLE type. Confidence level, strictly in (0,1).
Validity: Must be a DOUBLE scalar strictly in (0, 1).

antithetic BOOL type. Whether to also compute the mirror (antithetic) VaR.
Validity: Must be a BOOL scalar.
