User Guide

Market Risk: historical-simulation scenario generators (IR / credit curves, FX spot, FX volatility) and VaR / Expected Shortfall measures. This page contains 6 functions.

Every function that stores an object in ObjectCache accepts an optional final returnJson BOOL argument. Pass true to return [handle, protobufJson].

Example

loadPlugin("PluginCaplib")
vaR = caplib::calcVaR([-100.0, -50.0, 0.0, 50.0, 100.0], 0.95, false);

Market Risk

buildHistSimIrYieldCurve

Syntax

caplib::buildHistSimIrYieldCurve(simDate DATE, referenceCurve STRING, histStart STRING, histEnd STRING, curveDates DATE[], handle STRING[, returnJson BOOL])

Details

Build an IR yield-curve scenario by historical simulation (service HIST_SIM_IR_YIELD_CURVE_SCN_GENERATOR): interpolate the reference and historical curves onto the target curve dates.

IrYieldCurve handle

Return value

Returns: IrYieldCurve handle as stored in ObjectCache; with returnJson=true a [handle, protobufJson] pair is returned.

Parameters
ParameterType / ShapeDescription
simDateDATESimulation reference date.
referenceCurveSTRINGHandle of the reference IrYieldCurve.
histStartSTRINGHandle of the historical-start IrYieldCurve.
histEndSTRINGHandle of the historical-end IrYieldCurve.
curveDatesDATE[]Target dates on the output curve; at least two.
handleSTRINGObjectCache key for the result IrYieldCurve.

buildHistSimCreditCurve

Syntax

caplib::buildHistSimCreditCurve(simDate DATE, referenceCurve STRING, histStart STRING, histEnd STRING, curveDates DATE[], handle STRING[, returnJson BOOL])

Details

Build a credit-spread-curve scenario by historical simulation (service HIST_SIM_CREDIT_CURVE_SCN_GENERATOR). Same shape as buildHistSimIrYieldCurve with CreditCurve handles.

CreditCurve handle

Return value

Returns: CreditCurve handle as stored in ObjectCache; with returnJson=true a [handle, protobufJson] pair is returned.

Parameters
ParameterType / ShapeDescription
simDateDATESimulation reference date.
referenceCurveSTRINGHandle of the reference CreditCurve.
histStartSTRINGHandle of the historical-start CreditCurve.
histEndSTRINGHandle of the historical-end CreditCurve.
curveDatesDATE[]Target dates; at least two, with positive tenor.
handleSTRINGObjectCache key for the result CreditCurve.

buildHistSimFxSpotRate

Syntax

caplib::buildHistSimFxSpotRate(simDate DATE, referenceSpot STRING, histStart STRING, histEnd STRING, useTemplate BOOL, fxSpotTemplate STRING, handle STRING[, returnJson BOOL])

Details

Build an FX spot-rate scenario by historical simulation (service HIST_SIM_FX_SPOT_RATE_SCN_GENERATOR). Optionally applies an FxSpotTemplate.

FxSpotRate handle

Return value

Returns: FxSpotRate handle as stored in ObjectCache; with returnJson=true a [handle, protobufJson] pair is returned.

Parameters
ParameterType / ShapeDescription
simDateDATESimulation reference date.
referenceSpotSTRINGHandle of the reference FxSpotRate.
histStartSTRINGHandle of the historical-start FxSpotRate.
histEndSTRINGHandle of the historical-end FxSpotRate.
useTemplateBOOLWhether to apply an FX spot template; if true, fxSpotTemplate is required.
fxSpotTemplateSTRINGHandle of the FxSpotTemplate; empty when useTemplate is false.
handleSTRINGObjectCache key for the result FxSpotRate.

buildHistSimFxVolSurface

Syntax

caplib::buildHistSimFxVolSurface(simDate DATE, referenceVolSurf STRING, histStart STRING, histEnd STRING, volSurfaceDates DATE[], volSurfaceStrikes ANY, spot STRING, domCurve STRING, forCurve STRING, settings STRING, handle STRING[, returnJson BOOL])

Details

Build an FX volatility-surface scenario by historical simulation (service HIST_SIM_FX_VOL_SURFACE_SCN_GENERATOR) from reference and historical surfaces, a strike/target-date grid, spot rate, and domestic/foreign discount curves.

FxVolatilitySurface handle

Return value

Returns: FxVolatilitySurface handle as stored in ObjectCache; with returnJson=true a [handle, protobufJson] pair is returned.

Parameters
ParameterType / ShapeDescription
referenceVolSurf / histStart / histEndSTRINGHandles of the reference, historical-start and historical-end FxVolatilitySurface.
volSurfaceDatesDATE[]Target surface dates; at least two.
volSurfaceStrikesANYPer-date strike sets (a vector of DOUBLE[]); shape must match the date count.
spotSTRINGHandle of the FxSpotRate.
domCurveSTRINGHandle of the domestic IrYieldCurve.
forCurveSTRINGHandle of the foreign IrYieldCurve.
settingsSTRINGHandle of VolatilitySurfaceBuildSettings; may be empty.

calcVaR

Syntax

caplib::calcVaR(profitLossSamples DOUBLE[], probability DOUBLE, antithetic BOOL)

Details

Compute the Value-at-Risk of a profit-and-loss sample series (service CALCULATE_VALUE_AT_RISK).

DOUBLE

Return value

Returns: DOUBLE as stored in ObjectCache; with returnJson=true a [handle, protobufJson] pair is returned.

Parameters
ParameterType / ShapeDescription
profitLossSamplesDOUBLE[]Profit/loss sample series.
probabilityDOUBLEConfidence level, strictly in (0,1).
antitheticBOOLWhether to also compute the mirror (antithetic) VaR.
