Commodity

Commodity and precious-metal market data, quote matrices, volatility surfaces, and pricing.

📘 Full standard documentation (parameter values, error behavior) is in the Markdown version DQLIB_DOCUMENTATION.md.

User Guide

Commodity and precious-metal market data, quote matrices, volatility surfaces, and pricing. This page contains 25 functions. Use the filter to narrow by function name, return type, parameter, or description.

Argument validity: Each parameter states exact enum labels, selector codes, ranges, positivity, shape, and cross-argument rules. “Wrapper checks” are immediate plugin validation; “business-valid” rules may instead be enforced downstream.

Error behavior:Every function throws a DolphinDB RuntimeException on failure instead of returning a fallback scalar or partial object. Service calls returning success=false surface the service err_msg; validation, cache-class/handle, parsing, and serialization failures throw as well.

Example

loadPlugin("caplib")

cmQuoteMatrix = caplib::createCmOptionQuoteMatrix(
    "EUROPEAN", "FUTURE_UNDERLYING_TYPE", 2025.01.02,
    [2025.07.02, 2026.01.02], [["CALL", "PUT"], ["CALL", "PUT"]],
    [[100.0, 100.0], [105.0, 105.0]], [[7.1, 6.8], [8.4, 8.0]],
    "AU", "CM_QUOTES", true);

pricingResult = caplib::priceCmEuropeanOption(
    "CM_EUROPEAN", 2025.01.02, "CM_MKT", "CM_ANALYTICAL", "CM_RISK", "", "", true);

buildCmVolatilitySurface

Syntax

caplib::buildCmVolatilitySurface(asOfDate, underlying, definitionHandle, quoteMatrixHandle, underlyingPrices DOUBLE vector, discountCurveHandle, fwdCurveHandle, buildSettingsHandle, handle[, returnJson])

Details

Build and cache a commodity volatility surface. It resolves referenced ObjectCache entries, invokes the relevant build service, and caches the returned VolatilitySurface.

Return value

Created VolatilitySurface object on success. CAPLIB returns its ObjectCache handle; with returnJson=true, it returns [handle, protobufJson].

Parameters

asOfDate DATE type. Reference date for the created curve, surface, or build request.
Validity: Must be a non-null DolphinDB DATE scalar. It must not be later than a related end, expiry, delivery, or settlement date; the wrapper does not enforce this relationship.

underlying STRING type. Underlying asset, index, commodity, or currency-pair identifier.
Validity: Must be a non-empty STRING; the wrapper does not validate identifier character set or membership.

definitionHandle STRING type. ObjectCache handle for the definition object.
Validity: Must be non-empty and name an existing ObjectCache entry of the required protobuf type.

quoteMatrixHandle STRING type. ObjectCache handle for the option quote matrix.
Validity: Must be non-empty and name an existing ObjectCache entry of the required protobuf type.

underlyingPrices DOUBLE vector type. Underlying prices aligned with quote terms or calibration rows.
Validity: All elements must be finite and match the companion date vector; normally they are positive, but markets permitting negative prices are governed downstream.

discountCurveHandle STRING type. ObjectCache handle for the discount curve.
Validity: Must be non-empty and name an existing ObjectCache entry of the required protobuf type.

fwdCurveHandle STRING type. ObjectCache handle for the fwd curve object.
Validity: Must be non-empty and name an existing ObjectCache entry of the required protobuf type.

buildSettingsHandle STRING type. ObjectCache handle for the build settings object.
Validity: Must be non-empty and name an existing ObjectCache entry of the required protobuf type.

handle STRING type. ObjectCache key assigned to the created object and returned by the function.
Validity: Must be a non-empty ObjectCache key.

returnJson BOOL type. Optional. If omitted or false, returns only the ObjectCache handle; if true, returns [handle, protobufJson].
Validity: Must be a BOOL scalar; false and true are the only logical values.

caplib::buildPmYieldCurve(asOfDate, parCurveHandle, discountCurveHandle, pmTemplateHandle, spotPrice, calcJacobian, dayCountConvention, interpMethod, extrapMethod, curveType, curveName, shift, method, mode, handle[, returnJson])

Parameters

parCurveHandle STRING type. ObjectCache handle for the par-curve input object.

discountCurveHandle STRING type. ObjectCache handle for the discount curve.
Validity: Must be non-empty and name an existing ObjectCache entry of the required protobuf type.

pmTemplateHandle STRING type. ObjectCache handle for the pm template object.
Validity: Must be non-empty and name an existing ObjectCache entry of the required protobuf type.

spotPrice DOUBLE type. Spot price of the underlying or precious metal.
Validity: Must be strictly positive and finite; the wrapper generally checks only type.

calcJacobian INT type. Whether to calculate and return calibration Jacobian information.
Validity: Must be an INT scalar; 0 means false and non-zero means true; the plugin rejects BOOL values..

dayCountConvention STRING type. Day-count convention used for accrual or rate calculations.
Validity: Value must be one of these complete protobuf labels: ACT_360, ACTUAL_360, ACT_365_FIXED, ACTUAL_365_FIXED, ACT_ACT_ICMA, ACTUAL_ACTUAL_ICMA, ACT_ACT_ISMA, ACTUAL_ACTUAL_ISMA, ACT_ACT_ISDA, ACTUAL_ACTUAL_ISDA, THIRTY_360, BOND_BASIS, THIRTY_E_360, EUROBOND_BASIS, THIRTY_E_360_ISDA, ONE_ONE, THIRTY_U_360, THIRTY_U_360_EOM, THIRTY_360_PSA, THIRTY_E_360_PLUS, THIRTY_360_IT, ACT_ACT_AFB, ACTUAL_ACTUAL_AFB, ACT_364, ACTUAL_364, ACT_365_25, ACTUAL_365_25, ACT_365_ACT, ACTUAL_365_ACTUAL, ACT_365_L, ACTUAL_365_LONG, ACT_365_NL, ACTUAL_365_NO_LEAP, ACT_ACT_YEAR, ACTUAL_ACTUAL_YEAR, BUSINESS_252. These are canonical spellings; use them exactly for portability. Labels containing INVALID are parser-recognized sentinels and normally are not business-valid.

interpMethod STRING type. Interpolation method used between curve pillars.
Validity: Value must be one of these complete protobuf labels: LINEAR_INTERP, CUBIC_SPLINE_INTERP, LEFT_CONTINUOUS_FLAT_INTERP, SABR_INTERP, SVI_INTERP, LOG_MONEYNESS_CUBIC_SPLINE_INTERP, SABR_NORMAL_INTERP, QUADRATIC_POLYNOMIAL_INTERP, CUBIC_POLYNOMIAL_INTERP, CUBIC_HERMITE_SPLINE_INTERP. These are canonical spellings; use them exactly for portability. Labels containing INVALID are parser-recognized sentinels and normally are not business-valid. Observed behavior: The build service accepts only the LINEAR/CUBIC_SPLINE/LEFT_CONTINUOUS_FLAT/QUADRATIC_POLYNOMIAL/CUBIC_HERMITE_SPLINE subset; SABR/SVI/LOG_MONEYNESS/SABR_NORMAL are rejected by the service (verified 2026-10-15 in a fresh container).

extrapMethod STRING type. Extrapolation method used outside curve pillar range.
Validity: Value must be one of these complete protobuf labels: FLAT_EXTRAP, LINEAR_EXTRAP, NATURAL_EXTRAP, ADJ_FLAT_EXTRAP. These are canonical spellings; use them exactly for portability. Labels containing INVALID are parser-recognized sentinels and normally are not business-valid. Observed behavior: The build service accepts only the FLAT/LINEAR/ADJ_FLAT subset; NATURAL is rejected by the service (verified 2026-10-15 in a fresh container).

curveType STRING type. Curve value type, such as zero-rate, discount-factor, or spread curve.
Validity: Value must be one of these complete protobuf labels: ZERO_RATE, LOG_DISCOUNT, FORWARD_RATE. These are canonical spellings; use them exactly for portability. Labels containing INVALID are parser-recognized sentinels and normally are not business-valid. Observed behavior: The build service accepts only the ZERO_RATE/LOG_DISCOUNT subset; FORWARD_RATE is rejected by the service (verified 2026-10-15 in a fresh container).

curveName STRING type. Business name assigned to the curve.
Validity: Must be a non-empty STRING; the wrapper does not validate identifier character set or membership. Observed behavior: Passing NULL does not raise an exception; accepted leniently (verified 2026-10-15 in a fresh container).

shift DOUBLE type. Shift size used by curve build or risk calculations.
Validity: Must be a finite DOUBLE; unless stated otherwise it may be negative, zero, or positive, and the wrapper does not reject NaN/infinity.

method STRING type. Calculation, calibration, or finite-difference method selector.
Validity: Value must be one of these complete protobuf labels: CENTRAL_DIFFERENCE_METHOD, ONE_SIDE_DOWN_METHOD, ONE_SIDE_UP_METHOD. These are canonical spellings; use them exactly for portability. Labels containing INVALID are parser-recognized sentinels and normally are not business-valid.

mode STRING type. Optional remote execution mode or endpoint; pass an empty string for default mode.
Validity: Value must be one of these complete protobuf labels: SINGLE_THREADING_MODE, MULTI_THREADING_MODE. These are canonical spellings; use them exactly for portability. Labels containing INVALID are parser-recognized sentinels and normally are not business-valid.

handle STRING type. ObjectCache key assigned to the created object and returned by the function.
Validity: Must be a non-empty ObjectCache key.

returnJson BOOL type. Optional. If omitted or false, returns only the ObjectCache handle; if true, returns [handle, protobufJson].
Validity: Must be a BOOL scalar; false and true are the only logical values.

exerciseType STRING type. Exercise style of the option, such as European or American.
Validity: Value must be one of these complete protobuf labels: EUROPEAN, AMERICAN, BERMUDAN. These are canonical spellings; use them exactly for portability. Labels containing INVALID are parser-recognized sentinels and normally are not business-valid.

underlyingType STRING type. Underlying type enum used by the option instrument.
Validity: Value must be one of these complete protobuf labels: SPOT_UNDERLYING_TYPE, FUTURE_UNDERLYING_TYPE. These are canonical spellings; use them exactly for portability. Labels containing INVALID are parser-recognized sentinels and normally are not business-valid.

asOfDate DATE type. Market-data as-of date or valuation reference date for the created object.
Validity: Must be a non-null DolphinDB DATE scalar. It must not be later than a related end, expiry, delivery, or settlement date; the wrapper does not enforce this relationship.

termDates DATE vector type. Absolute quote term or expiry dates aligned with quote rows.
Validity: Must be a DATE/INT date vector without nulls; length must match its companion argument. When it represents a schedule or term series it should normally be strictly increasing; the wrapper does not enforce sorting or chronology.

payoffTypes STRING 矩阵/向量 type. Payoff type matrix or vector aligned with option quote values.
Validity: Each element must be one of these complete protobuf labels: CALL, PUT, STRADDLE, STRANGLE, RISK_REVERSAL, BUTTERFLY, ATM_STRADDLE. These are canonical spellings; use them exactly for portability. Labels containing INVALID are parser-recognized sentinels and normally are not business-valid.

strikes DOUBLE 矩阵/向量 type. Strike levels aligned with option quotes or volatility rows.
Validity: Must be finite; price-underlying strikes are normally non-negative, while rate-underlying strikes may be negative. The wrapper checks only type/shape.

prices DOUBLE 矩阵/向量 type. Option prices or market prices aligned with strikes and maturities.
Validity: All elements must be non-negative and finite, with shape matching companion strikes/terms; the wrapper primarily checks type/shape.

underlying STRING type. Underlying asset, index, commodity, or currency-pair identifier.
Validity: Must be a non-empty STRING; the wrapper does not validate identifier character set or membership.

handle STRING type. ObjectCache key assigned to the created object and returned by the function.
Validity: Must be a non-empty ObjectCache key.

returnJson BOOL type. Optional. If omitted or false, returns only the ObjectCache handle; if true, returns [handle, protobufJson].
Validity: Must be a BOOL scalar; false and true are the only logical values.
