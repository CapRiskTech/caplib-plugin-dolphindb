User Guide

Commodity and precious-metal market data, quote matrices, volatility surfaces, and pricing. This page contains 25 functions. Use the filter to narrow by function name, return type, parameter, or description.

Argument validity: Each parameter states exact enum labels, selector codes, ranges, positivity, shape, and cross-argument rules. “Wrapper checks” are immediate plugin validation; “business-valid” rules may instead be enforced downstream.

Example

cmQuoteMatrix = caplib::CreateCmOptionQuoteMatrix(
    "EUROPEAN", "FUTURE_UNDERLYING_TYPE", 2025.01.02,
    [2025.07.02, 2026.01.02], [["CALL", "PUT"], ["CALL", "PUT"]],
    [[100.0, 100.0], [105.0, 105.0]], [[7.1, 6.8], [8.4, 8.0]],
    "AU", "CM_QUOTES", true);

pricingResult = caplib::PriceCmEuropeanOption(
    "CM_EUROPEAN", 2025.01.02, "CM_MKT", "CM_ANALYTICAL", "CM_RISK", "", "", true);

BuildCmVolatilitySurface

Build and cache a commodity volatility surface. It resolves referenced ObjectCache entries, invokes the relevant build service, and caches the returned VolatilitySurface.

caplib::BuildCmVolatilitySurface(referenceDate DATE, underlying STRING, definitionHandle STRING, quoteMatrixHandle STRING, underlyingPrices DOUBLE[], discountCurveHandle STRING, fwdCurveHandle STRING, buildSettingsHandle STRING, handle STRING[, returnJson BOOL])

VolatilitySurface

Returns: Created VolatilitySurface object on success. CAPLIB returns its ObjectCache handle; with returnJson=true, it returns [handle, protobufJson]. Status/error behavior: For service-backed calls, success=true means the documented result was produced, while success=false means no valid result was produced and the service err_msg is surfaced in a DolphinDB RuntimeException. Wrapper-only operations expose no status scalar. Validation, cache-class/handle, parsing, and serialization failures also throw, so every error is observed as an exception rather than a fallback scalar or partial object.

Validity: Must be non-empty and name an existing ObjectCache entry of the required protobuf type.
