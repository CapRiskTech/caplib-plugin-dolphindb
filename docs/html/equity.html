User Guide

Equity market data, dividend curves, volatility surfaces, option instruments, and EQ pricing. This page contains 36 functions. Use the filter to narrow by function name, return type, parameter, or description.

Argument validity: Each parameter states exact enum labels, selector codes, ranges, positivity, shape, and cross-argument rules. “Wrapper checks” are immediate plugin validation; “business-valid” rules may instead be enforced downstream.

Error behavior:Every function throws a DolphinDB RuntimeException on failure instead of returning a fallback scalar or partial object. Service calls returning success=false surface the service err_msg; validation, cache-class/handle, parsing, and serialization failures throw as well.

Example

loadPlugin("caplib")

eqRisk = caplib::createEqRiskSettings(0, 0, 0, 0, "EQ_NO_RISK", true);
eqMkt = caplib::createEqMktDataSet(
    2025.01.02, "EQ_UNDERLYING", 100.0,
    "USD_DISC", "EQ_DIV", "EQ_VOL", "", "", 0.0, "EQ_MKT", true);

pricingResult = caplib::priceEqEuropeanOption(
    "EO_INST", 2025.01.02, eqMkt[0], "BSM_ANALYTICAL", eqRisk[0], "", "", true);
resultJson = pricingResult[1];

mode STRING type. Optional remote execution mode or endpoint; pass an empty string for default mode.
Validity: May be empty for the default mode; non-empty values are passed verbatim to the downstream service, and the plugin defines no local enum or character range.

returnJson BOOL type. Optional. If omitted or false, returns only the ObjectCache handle; if true, returns [handle, protobufJson].
Validity: Must be a BOOL scalar; false and true are the only logical values.
