Every function that stores an object in ObjectCache accepts an optional final returnJson BOOL argument. If omitted or false, the function returns only the handle. Pass true to return [handle, protobufJson].

Argument validity: Each parameter states exact enum labels, selector codes, ranges, positivity, shape, and cross-argument rules. “Wrapper checks” are immediate plugin validation; “business-valid” rules may instead be enforced downstream.
