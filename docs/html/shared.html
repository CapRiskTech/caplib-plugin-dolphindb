User Guide

Cross-asset utilities, pricing settings, risk settings, scenario settings, and shared protobuf tooling. This page contains 28 functions. Use the filter to narrow by function name, return type, parameter, or description.

Every function that stores an object in ObjectCache accepts an optional final returnJson BOOL argument. If omitted or false, the function returns only the handle. Pass true to return [handle, protobufJson].

Argument validity: Each parameter states exact enum labels, selector codes, ranges, positivity, shape, and cross-argument rules. “Wrapper checks” are immediate plugin validation; “business-valid” rules may instead be enforced downstream.

Error behavior:Every function throws a DolphinDB RuntimeException on failure instead of returning a fallback scalar or partial object. Service calls returning success=false surface the service err_msg; validation, cache-class/handle, parsing, and serialization failures throw as well.

Example

loadPlugin("caplib")

settings = caplib::createPricingSettings(
    "USD", "ANALYTICAL", 0, 0, take(0, 0),
    "BSM_MODEL", "", "", "BSM_ANALYTICAL", false);

json = caplib::getObjectCacheJson("PricingSettings", settings);

calcYearFraction

Syntax

caplib::calcYearFraction(startDate, endDate, dayCountConvention)

Details

Calculates the accrual year fraction from startDate to endDate by applying the selected day-count convention through the CAPLIB date service.

Return value

A double accrual year fraction.

Parameters

startDate DATE type. Start date of the schedule, accrual period, or instrument.
Validity: Must be a non-null DolphinDB DATE scalar. It must not be later than a related end, expiry, delivery, or settlement date; the wrapper does not enforce this relationship.

endDate DATE type. End date of the schedule, accrual period, or instrument.
Validity: Must be a non-null DolphinDB DATE scalar. It must not precede a related start, issue, or reference date; the wrapper does not enforce this relationship.

dayCountConvention STRING type. Day-count convention used for accrual or rate calculations.
Validity: Accepted values: ACT_360, ACTUAL_360, ACT/360, ACT_365, ACT_365_FIXED, ACTUAL_365_FIXED, ACT/365, ACT_ACT, ACT_ACT_ISDA, ACTUAL_ACTUAL_ISDA, ACT_ACT_ICMA, ACTUAL_ACTUAL_ICMA, THIRTY_360, 30_360, 30/360, BOND_BASIS. Matching is case-insensitive.

createCalendar

Syntax

caplib::createCalendar(calName[, holidays DATE vector|INT vector[, specialBusinessDays DATE vector|INT vector]])

Details

Builds a Calendar from the supplied name, holidays, and exceptional business days, serializes it as CalendarList static data, and registers it with CAPLIB.

Return value

Bool true after calendar registration (failure throws; false is never returned).

Parameters

calName STRING type. Calendar name to register in caplib static data.
Validity: Every name must be a non-empty registered calendar identifier.

holidays DATE or INT vector type. Optional holiday dates. DATE values are converted to the Python-style ordinal serials expected by the calendar protobuf.
Validity: Must be a DATE/INT date vector without nulls; length must match its companion argument. When it represents a schedule or term series it should normally be strictly increasing; the wrapper does not enforce sorting or chronology.

specialBusinessDays DATE or INT vector type. Optional special business-day dates. DATE values are converted to the Python-style ordinal serials expected by the calendar protobuf.
Validity: Must be a DATE/INT date vector without nulls; length must match its companion argument. When it represents a schedule or term series it should normally be strictly increasing; the wrapper does not enforce sorting or chronology.

strike DOUBLE type. Option strike level.
Validity: Rate strikes must be finite and may be negative, zero, or positive; the wrapper checks only type/shape.
